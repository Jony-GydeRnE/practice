# Practice repository

This repository also contains a standalone **Mandarin Anatomy Trainer** web app under [`docs/`](./docs/).

## Mandarin Anatomy Trainer — start here

**[Read the complete vision and product specification](./docs/README.md)**

The learning plan starts with one proven character card (`好`), expands through the learner's original **50 characters and 17 compounds**, builds an approximately **100-character high-utility everyday Mandarin foundation**, then grows into **semantic-component/radical families**, **phonetic series**, and practical conversational categories.

The end goal is to *understand how characters were built*, recognize phonetic and semantic clues, hear natural Mandarin, record and replay pronunciation, earn fair partial-credit grades, and practice cumulative, randomized, **grammatically meaningful** sentences.

- [Current mobile prototype](./docs/index.html)
- [Full learning philosophy, curriculum, grading rules, roadmap, implementation status, and instructions for future chats](./docs/README.md)

The mobile web version is intended for GitHub Pages deployment from **`master` → `/docs`**, with HTTPS required for browser microphone access. The proposed URL is `https://jony-gyderne.github.io/practice/` once Pages publishing is enabled and verified.

**For future AI/code sessions:** Read `docs/README.md` before modifying the Mandarin app. Its implementation-status section distinguishes working features from planned features, and the existing root-level practice code should not be disturbed by this subproject.
